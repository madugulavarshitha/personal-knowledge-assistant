# Personal Knowledge Assistant

AI-powered personal knowledge assistant built using Flask, Gemini AI, and Google Sheets.

## Live Demo
🌐 https://postal-budget-enjoyably.ngrok-free.dev

## Features
- AI Summarization
- Smart Search
- Google Sheets Integration
- Audio and Video Support

## Technologies Used
- Python
- Flask
- Gemini API
- Google Sheets API
- HTML, CSS, JavaScript

## Installation
```bash
pip install -r requirements.txt
python main.py
```
